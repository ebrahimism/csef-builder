# گزارش پذیرش محدود T002

تاریخ محلی: ۱۶ نوامبر ۲۰۲۶، منطقهٔ زمانی Asia/Dubai.

## رفتار مشاهده‌شده

منبع رسمی github/spec-kit در commit `2ee2b1e8005905db05f5717300a469b3068b908f`
بررسی شد. نسخهٔ ثبت‌شده در آن `1.4.1.dev0` است؛ ادعای آخرین release پایدار نداریم.
فایل‌های مرجع و مجوز به همراه SHA-256 ثبت شدند. کد native فقط در محیط موقت همین
پروژه نصب شد و نسخه و هش فایل‌های نصب‌شده هنگام اجرای آزمایش دوباره کنترل شدند.

خروجی واقعی نیازهای REQ-101 تا REQ-107 و یک ADR فارسی چندخطی، همراه نسخه و منشأ،
بدون تغییر رفت‌وبرگشت کرد. spec/plan/tasks به‌عنوان متن کامل پیشنهادی حفظ می‌شوند.
import هدف صاحب پروژه یا stageها را اصلاح نمی‌کند؛ نتیجه همیشه پیشنهاد است.

در آزمون‌های متمرکز، ثبت تکراری پس از بازگشایی و ورود هم‌زمان فقط یک پیشنهاد ساخت؛
تغییر نسخه یا متن هدف و ورود به کتاب پروژهٔ دیگر رد شد؛ export فایل موجود را
بازنویسی نکرد. PASS متنی، تیک tasks و دستور داخل Markdown اثری بر پذیرش نداشتند.

آزمایش موتور واقعی، override محلی را از resolver خود Spec Kit گرفت. پس از import،
دروازهٔ بدون رأی متوقف ماند؛ resume بدون رأی هم متوقف ماند. approve توانست فقط گردش‌کار
native را تمام کند، درحالی‌که هدف، وضعیت مراحل و اختیار CSEF تغییر نکردند. پس از قطع
شبیه‌سازی‌شده میان commit پیشنهاد و ثبت نتیجهٔ مرحله، اجرای دوباره همان پیشنهاد را
برگرداند و شمار پیشنهاد ثابت ماند. reject گردش‌کار native را aborted کرد. ورودی با
نسخهٔ کهنه نیز پس از اصلاح صریح هدف رد شد.

## تصمیم و حدود نتیجه

قالب‌ها و فرایند سندمحور، همراه adapter پیشنهاد، برای این برش پذیرفته شدند. موتور
native به‌عنوان منبع اختیار پذیرفته نشد. نصب preset عمومی، agent integration جدید،
مدل‌خوانی یا اجرای workflow دلخواه انجام نشد؛ دلیل کنارگذاشتن این بخش‌ها در
`integrations/spec-kit/preset/README.md` ثبت شده است.

اثر پشتیبانی‌شده فقط ثبت پیشنهاد محلی است. عملیات خارجی، قطع برق، خرابی ذخیره‌سازی
و اجرای کد ناشناس آزمایش نشده‌اند. نتیجهٔ نامعلوم عملیات خارجی مجوز retry نیست.
هش و binding مسیر جای هویت معتبر و مرز دسترسی را نمی‌گیرند. محدودیت loopback ویندوز
و باقی‌ماندن وضعیت سنجش در REVIEW پابرجاست.

تعداد فراخوانی مدل در workflow آزمایشی صفر است. برای ارزیابی مهندسی یک نشست جدا
استفاده شد؛ زمان آن در گزارش بازبین و زمان اجرا در رسید ثبت است. مصرف توکن و قیمت
کلی اندازه‌گیری نشده‌اند؛ ادعای کاهش هزینه یا بهبود عمومی کیفیت نداریم. زمان دیواری
کار و مجموع زمان فرایندهای آزمایش در `T002-effort.json` ثبت شده‌اند و زمان فعال
کاربر یا هزینهٔ مدل محسوب نمی‌شوند.
