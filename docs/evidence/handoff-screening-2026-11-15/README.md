# Six-stage screening evidence — 2026-11-15

`summary.json` contains comparable per-project totals, allocating the same three shared
design calls to every arm. Those artifacts were generated once and reused, not billed
three times. `results.json` includes all stage outcomes, reviewer findings and limits.
`model-receipts.json` includes 17 logical source calls, including four reused artifacts
from the infrastructure-interrupted layout. The implementation loop used fresh calls
with the same default CLI selection, not deliberately different model providers.

Each arm passed 4 + 8 + 13 = 25 staged behavioral observations and the explicit module
import checks. There were no coding retries in the valid run. The shared document
stages were checked for shape/ID coverage, not full semantic architecture correctness.

With shared design cost, compact context reduced total input by 8.68% and uncached
input by 4.18%. Reviewing every coding stage increased total input by 52.85% over compact
context with no observed gain in this test suite. Tokens, cached input, output and
subscription terms have different cost implications; no dollar saving is claimed.
Order was fixed and there were no independent repetitions. This is a screening result.

The first layout failed at sandbox startup. Its code scores are invalid. Reused artifacts
and the extra completed receipts are disclosed in `summary.json`; development overhead
is not represented as runtime savings. All recorded provider calls had completed when
the process was stopped, so no unknown model bill is invented.

Two reviewer canaries were also run: an unapproved cloud/data-loss change was flagged;
a legitimate CSV addition was returned for contract clarification. These obvious cases
do not establish reviewer accuracy on subtle architectural errors.

`guided-interview-result.json` is a separate real model call. Given instant cross-city
sync and a prohibition of all communication, it identified the contradiction, asked one
material question in Persian and kept owner facts unchanged. `pending-question-recheck.json`
shows a repeat CLI request returned the saved question with no additional model call.

This evidence does not measure actual human effort, provider availability, hidden-goal
retention on large repositories or advanced-application success. Native loopback network
isolation remains incomplete. All execution was reviewed local measurement, not release
acceptance. The selected targeted-review policy is implemented and mechanically tested;
its quality advantage has not been benchmarked as a fourth arm.
